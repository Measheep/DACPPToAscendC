# Support

## Questions and Bug Reports

Use the repository issue tracker for reproducible build, translation, and
generated-code problems. Include:

- the exact DACPPToAscendC revision;
- operating system, compiler, CMake, Ninja, LLVM/Clang, and Python versions;
- CANN version and Ascend device model when device compilation or execution is
  involved;
- the complete command and minimal DACPP input;
- expected and actual behavior; and
- sanitized diagnostics produced with `--debug`, when needed.

Do not attach credentials, proprietary source, complete environment dumps, or
CANN SDK binaries. Use `SECURITY.md` instead of a public issue for anything
that may be a vulnerability.

## Support Boundaries

The project currently provides community support without a guaranteed response
time. Source-generation tests do not prove compatibility with every CANN
release or Ascend device. Questions about installing or licensing CANN should
be directed to Huawei's official support channels.
